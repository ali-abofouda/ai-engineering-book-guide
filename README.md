# AI Engineering — Book Guide

مرجع وشرح تفصيلي شامل (**صفحة بصفحة** ولكل فصل) لكتاب **AI Engineering: Building Applications with Foundation Models** للكاتبة **Chip Huyen** (O'Reilly).

## مهمة الريبو ومنهجية الشرح

الهدف من هذا الريبو هو تقديم **شرح تفصيلي ممل (Deep-Dive)** لكل فصل ولكل صفحة في الكتاب دون اختصار مُخلّ، بحيث يغطي الشرح لكل صفحة:
- **كل الأفكار والفقرات** بتسلسلها الدقيق داخل الصفحة.
- **المصطلحات التقنية بالإنجليزية** مع شرحها بالعربية وربطها بالسياق العملي.
- **الرسومات التوضيحية، الجداول، المعادلات، وأمثلة الكود** المشروحة في الصفحة.
- **المقارنات والـ Trade-offs** وحالات الدراسة (`Case Studies`) والملاحظات الهامشية المهمة.
